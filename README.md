# AI Leaderboard

An AI model leaderboard aggregator: it ingests public evaluation boards (LMArena, Epoch AI, plus OpenRouter metadata/pricing), maps them onto one canonical model identity, and publishes cross-board rankings, disagreement flags, trend charts and prices as a statically generated, SEO-first Next.js site in 7 languages (en, zh, es, de, fr, ja, pt), with special focus on Chinese models vs. global models. Spec: [SPEC.md](SPEC.md) · Full architecture (Chinese): [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). All code in this repo is written by Claude Code.
